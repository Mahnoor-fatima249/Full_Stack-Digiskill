# Personal Profile Web Page

## Project Description
This is a Personal Profile Web Page created using HTML and CSS. The page displays personal information, skills, and contact details in a modern, responsive design.

## Features
- Responsive design for all screen sizes
- Modern gradient color scheme (Brown/Cream theme)
- Interactive hover effects
- Clean card layout
- Mobile-friendly interface

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Poppins)

## Sections
1. **Header** - Profile picture, name, and tagline
2. **About Me** - Personal introduction
3. **Skills** - Technical skills with tags
4. **Contact** - Email, phone, location, and GitHub links

## How to View
1. Download or clone the repository
2. Open `profile.html` or `index.html` in any web browser
3. The page will display with full styling
